# 와쳐스 WATCHERS (학교 과제용 시연 앱)

## 실행 방법
1. Python을 설치합니다.
2. 터미널(명령 프롬프트)에서 이 폴더로 이동합니다.
3. 아래 명령어를 실행합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 구성
- `app.py`: 홈, 중앙부처, 정책광장, 의견광장, 마이페이지 화면
- `requirements.txt`: 실행에 필요한 Python 패키지

## 참고
이 앱은 화면 시연을 위한 정적 예시입니다. 실제 정부 데이터/API, 로그인, 데이터베이스, 투표 저장, 의견 전송 기능은 연결되어 있지 않습니다. 화면에 표시되는 정책명과 수치 및 기관 정보는 가상 예시입니다.
